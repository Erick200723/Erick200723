## Sobre mim

Sou **desenvolvedor Full Stack** com foco em **Back-end**, construindo sistemas que vão de APIs REST a arquiteturas distribuídas com integração de hardware.

Trabalho principalmente com **TypeScript**, **Node.js** e **Fastify**, desenvolvendo aplicações com autenticação robusta, integrações de gateways de pagamento, comunicação em tempo real via WebSocket e deploy containerizado com Docker — sempre pensando em **escala**, **manutenção** e **boas práticas**.

Tenho projetos reais em produção com contratos ativos, incluindo plataformas web para eventos internacionais e sistemas de gestão clínica com integração de hardware físico.
